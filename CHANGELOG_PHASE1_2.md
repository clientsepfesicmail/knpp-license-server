# Tezhisab Central Portal Phase 1.2

## Full Product Name Display Fix

- App Update Manager now shows full software names instead of confusing short codes such as `BIP`, `TSP`, `EEM`, and `THP`.
- Publish Version dropdown now displays labels such as `Bank Import Pro — Windows Desktop — EXE`.
- Update Channels table and Published Versions table show the full product name prominently.
- Internal product codes remain stored in the backend for API compatibility with existing desktop apps.
- No Supabase SQL change is required for this update.
